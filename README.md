# HEKAN Bible

HEKAN Bible is a modern offline Bible application built with Flutter.

## Features

- 📖 Offline Bible
- 🔍 Bible Search
- 🙏 Morning & Evening Prayers
- 🎵 English & Hausa Hymns
- 🔖 Bookmarks
- 📝 Notes
- 🌙 Dark Mode
- 🔔 Daily Verse Notifications
- ☁️ Firebase Authentication
- 📱 Responsive UI

## Built With

- Flutter
- Firebase
- SQLite
- Cloud Firestore
